## 二、WorkBuddy 发布流程（拿体验链接）

1. WorkBuddy 首页切换「开发」模式 → 选「开发网站」
2. 先本地跑 `node tools/build-singlefile.mjs` 生成最新 `dist/index.html`（约 57 KB，单文件）
3. 把下面这段 prompt 贴给它，并在末尾附上 dist/index.html 全文（或作为附件上传）：

```text
请帮我把一个已经完成的单文件网页游戏部署为可公开访问的网站，用于参加 WorkBuddy 1024 造物挑战。严格按以下要求执行：

【任务】
1. 在当前项目中创建文件 index.html，内容 = 我在本条消息最下方贴出的全部代码，一字不改。
2. 这是纯静态单文件游戏：HTML/CSS/JS 已全部内联，无外部依赖，无需构建、无需安装任何包。
3. 创建后打开预览，逐项自查：
   - 页面标题为「SkyDispatch · 低空塔台」，深色雷达风格界面正常渲染；
   - 主菜单出现「自由调度」和「每日挑战」两个按钮；
   - 点「自由调度」能开局：任务申请出现在右侧、点「批准」后有无人机起飞、倒计时在走。
4. 自查全部通过后，将网站发布为公开可访问链接，并把链接发给我。

【硬性约束】
- 不得修改、重构、格式化或"优化"我提供的代码，一个字符都不要动；
- 如预览异常，只允许做最小必要修复，并向我说明改了哪几行；
- 不要拆分文件、不要引入框架或外部资源、不要添加统计/广告/水印；
- 发布前不要改动 <title> 和 <meta> 标签。

【代码】
（在这里粘贴 dist/index.html 的全部内容；若放不下，分两条消息，上一条声明"代码在下一条"；或直接上传 dist/index.html 附件并改为"代码见附件"）
```

4. 预览确认能玩（重点试手机预览）
5. 点「发布为网站」→ 右上角「分享」→ 复制公开访问链接
6. **用无痕窗口打开链接自测一遍**：能开始、能批准、能打完一局出报告，才算有效链接
