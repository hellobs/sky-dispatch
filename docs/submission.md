## 二、WorkBuddy 发布流程（拿体验链接）

1. WorkBuddy 首页切换「开发」模式 → 选「开发网站」
2. 把 `dist/index.html` 的全部内容贴给它（先本地跑 `node tools/build-singlefile.mjs` 重新生成，确保是最新版），提示词示例：
   > 这是一个完整的单文件网页游戏（HTML/CSS/JS 已全部内联）。请原样创建为网站首页，不要改动任何代码，创建后直接发布。
3. 预览确认能玩（重点试手机预览）
4. 点「发布为网站」→ 右上角「分享」→ 复制公开访问链接
5. **用无痕窗口打开链接自测一遍**：能开始、能批准、能打完一局出报告，才算有效链接
