# SkyDispatch · 低空塔台

> 这个 1024，我做了一个低空塔台，让城市上空的每一架无人机都准时起飞、安全落地。

城市低空无人机调度小游戏。玩家扮演低空塔台的调度员：审批不断涌入的飞行申请、规划航线、避开禁飞区与天气团、防止无人机冲突——撑住的架次越多，得分越高。

参赛作品：WorkBuddy「1024 造物挑战」程序员节应用创作大赛（截稿 2026-11-01 23:59）。

## 核心玩法

1. **申请涌入**：送货 / 巡检 / 救援等任务以一定频率申请起飞，各有起讫点与时限
2. **调度决策**：批准或拒绝、画航线、分配高度层；放行太慢会积压（扣准点率），放行太随意会撞机（直接扣分/结束）
3. **动态威胁**：禁飞区、移动天气团随时间刷新，需要临时改航或召回
4. **结算报告**：一局结束给出「今日调度报告」——架次 / 准点率 / 冲突数 / 得分，适合截图分享

## MVP 范围（v0.1）

- [ ] 单屏网格空域图（canvas 绘制，无人机、禁飞区、天气团）
- [ ] 任务申请队列 + 批准/拒绝交互
- [ ] 简单航线（点击途经点）与沿路飞行、到达结算
- [ ] 冲突判定（同格/近距离碰撞）
- [ ] 一局 3 分钟 + 结算报告页
- [ ] 难度随时间递增（申请频率、天气刷新）

## 后续迭代（候选）

- 高度层机制（同格不同高度可共存）
- 道具 / 事件卡（备降点、雷达加速）
- 排行榜、每日一局（固定种子）
- 1024 彩蛋（如生涯成就「单日调度 1024 架次」）
