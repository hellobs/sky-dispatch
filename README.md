# SkyDispatch · 低空塔台

> 这个 1024，我做了一个低空塔台，让城市上空的每一架无人机都准时起飞、安全落地。

城市低空无人机调度小游戏。玩家扮演低空塔台的调度员：审批不断涌入的飞行申请、规划航线、避开禁飞区与天气团、防止无人机冲突——撑住的架次越多，得分越高。

参赛作品：WorkBuddy「1024 造物挑战」程序员节应用创作大赛（截稿 2026-11-01 23:59）。

## 核心玩法

1. **申请涌入**：送货 / 巡检 / 救援等任务以一定频率申请起飞，各有起讫点与时限
2. **调度决策**：批准或拒绝、画航线、分配高度层；放行太慢会积压（扣准点率），放行太随意会撞机（直接扣分/结束）
3. **动态威胁**：禁飞区、移动天气团随时间刷新，需要临时改航或召回
4. **结算报告**：一局结束给出「今日调度报告」——架次 / 准点率 / 冲突数 / 得分，适合截图分享

## MVP 范围（v0.1）

- [ ] 单屏网格空域图（canvas 绘制，无人机、禁飞区、天气团）
- [ ] 任务申请队列 + 批准/拒绝交互
- [ ] 简单航线（点击途经点）与沿路飞行、到达结算
- [ ] 冲突判定（同格/近距离碰撞）
- [ ] 一局 3 分钟 + 结算报告页
- [ ] 难度随时间递增（申请频率、天气刷新）

## 运行方式

纯静态、零构建、零依赖，两种方式任选：

- 直接双击 `index.html` 用浏览器打开
- 或在项目目录起个静态服务器：`python -m http.server 8765`，访问 `http://127.0.0.1:8765`

## 操作说明

- 点击右侧申请卡片上的「批准 / 拒绝」进行调度；批准后无人机立即从起降点起飞
- 鼠标悬停申请卡，地图上会预览该单航线
- 空格键暂停/继续；Enter 开始或再来一局
- 一局 3 分钟，结束后出「今日调度报告」，可一键复制战绩文案

## 技术与开发约定

- 纯前端实现（canvas + 原生 JS），无框架无后端；最终在 WorkBuddy 内发布为网站参加比赛
- 投稿前运行 `node tools/build-singlefile.mjs` 生成单文件 `dist/index.html`（CSS/JS 已内联），便于贴入 WorkBuddy「开发网站」模式
- 提交信息用英文祈使句，如 `feat: add flight request queue`
- ⚠️ 隐私红线：代码、截图、文案中不得出现真实姓名、学校、实验室、项目涉密内容

## 目录结构

```
sky-dispatch/
├── index.html            # 页面骨架（HUD / 画布 / 申请面板 / 浮层）
├── css/style.css         # 暗色雷达风样式
├── js/
│   ├── utils.js          # 通用工具
│   ├── config.js         # 全部数值配置（调平衡只改这里）
│   ├── airspace.js       # 空域：网格、起降点、禁飞区、风暴
│   ├── drone.js          # 无人机实体（移动/航迹/坠毁）
│   ├── missions.js       # 任务申请生成与调度队列
│   ├── ui.js             # DOM 界面：HUD、申请队列、浮层
│   ├── game.js           # 主循环、规则结算、评分
│   └── main.js           # 启动、输入绑定、循环调度
├── tools/
│   └── build-singlefile.mjs  # 单文件打包脚本
└── docs/                 # 设计笔记（待建）
```
